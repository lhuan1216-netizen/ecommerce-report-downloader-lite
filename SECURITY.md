# Security policy

## Data handling

- The extension does not ask for or persist account passwords, cookies, or verification codes.
- Authentication remains inside the user's Chrome profile.
- Downloaded reports stay in the user's Chrome download directory.
- The host permission is limited to `https://sycm.taobao.com/*`.

## Reporting a vulnerability

Do not open a public issue containing credentials, cookies, report data, or store identifiers. The repository owner should add a private security contact before publication.

## User responsibility

Install only after reviewing the source and declared Chrome permissions. Use the extension only with accounts and data that you are authorized to access.
