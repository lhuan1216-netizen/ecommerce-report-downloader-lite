# 生意参谋商品报表下载器

这是一个本地 Chrome 扩展，用于在已登录的生意参谋后台下载商品排行报表。

## 当前能力

- 支持昨天、近 7 天、近 30 天，以及自定义单日商品排行报表。
- 支持为当前 Chrome 用户配置填写账号/店铺名称，并按账号保存任务状态。
- 报表自动整理到 Chrome 下载目录下的 `生意参谋报表/账号或店铺名称/`。
- 页面重新加载后从本地任务状态继续。
- 在后台标签页运行，不抢占当前正在使用的页面。
- 页面操作或下载失败最多自动重试 3 次。
- 通过 Chrome 下载事件确认文件真正开始并完成下载。
- 下载完成后核验文件名中的实际日期；平台数据尚未更新时，保留最新可用报表并明确提示日期回退。
- 保存最近运行日志和页面检查结果，不保存密码、Cookie 或验证码。
- 只允许在 `https://sycm.taobao.com/*` 上执行页面操作。

## 安装（联调阶段）

1. 在 Chrome 打开 `chrome://extensions`。
2. 打开“开发者模式”。
3. 选择“加载已解压的扩展程序”。
4. 选择克隆后的项目目录。

开启开发者模式、加载未上架扩展和授予生意参谋页面权限均会扩大浏览器访问能力，应只在确认本项目源码后执行。

## 使用

1. 在 Chrome 登录生意参谋并保持标签页打开。
2. 填写当前 Chrome 用户配置对应的账号或店铺名称。
3. 选择报表周期；选择“自定义日期”时可指定昨天或更早的任意一天。
4. 点击“开始下载”。
5. 遇到验证码或重新登录时由用户完成，再点击“继续任务”。

多账号使用时，每个账号使用一个独立的 Chrome 用户配置，并在其中安装本扩展。这样各账号的 Cookie 和登录状态不会互相覆盖。

## 安全边界

- 不读取或保存登录凭据、Cookie、验证码。
- 不修改商品、订单、广告、店铺设置。
- 不绕过平台权限、验证码或风控提示。
- 下载文件沿用 Chrome 自己的下载目录和安全检查。
